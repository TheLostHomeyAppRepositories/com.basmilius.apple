# Apple TV & HomePod for Homey

Control Apple TV, HomePod and HomePod Mini from Homey over your local network. The app connects playback controls and now-playing information to Homey devices, Flow cards and dashboard widgets.

## Supported devices

| Device | Controls and information |
| --- | --- |
| Apple TV | Remote navigation, playback, power, app launching, account switching and now-playing information |
| HomePod and HomePod Mini | Playback, volume, repeat, shuffle, audio URL playback and now-playing information |

Use Flows to pause playback when the doorbell rings, launch an app for movie night, or react when the active Apple TV app changes. Available controls depend on the device.

## Setup

Use a local Homey running version 12.9 or newer. Homey and your Apple devices must be reachable on the same local network.

Add a device through Homey and follow the discovery and pairing screens. Apple TV pairing asks for the PIN displayed on the television.

## Source layout

The integration uses the Apple SDK and audio-source packages by Bas Milius. Device drivers are in `drivers/`; shared connection code and device-specific behavior are in `src/base/`, `src/apple-tv/` and the `src/homepod*` directories. Dashboard widgets live in `widgets/`.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
```

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
